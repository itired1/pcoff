# ⏻ Shutdown Timer

Умный таймер выключения ПК для Windows 10/11 с современным минималистичным
интерфейсом в стиле Windows 11 / macOS Sonoma.

![version](https://img.shields.io/badge/version-1.3.0-blue)
![python](https://img.shields.io/badge/python-3.10%2B-blue)
![platform](https://img.shields.io/badge/platform-Windows-0078D6)
![license](https://img.shields.io/badge/license-MIT-green)

## ✨ Возможности

### ⏱ Таймер
- **Умный ввод** — одно поле понимает `1233`, `30м`, `1ч30м`, `завтра в 9`,
  `через полчаса`, `in 30 minutes`, `вечером`, `в полночь` и ещё 20+ форматов.
- **Живой предпросмотр** — при наборе сразу видно результат: `сегодня в 12:33 · через 2 ч 15 мин`.
- **Пресеты** — 15м / 30м / 1ч / 2ч / 4ч.
- **Пауза и продолжение** — с сохранением остатка.

### ⚡ Триггеры по событиям
- **Steam** — завершение установки **конкретной игры** из списка активных
  загрузок (с прогресс-баром в реальном времени и процентами).
- **Программа** — выключение при закрытии `.exe` (Notepad, VLC, игра, что угодно).
- **Батарея** — срабатывание при падении заряда ниже N%.

### 📱 Синхронизация с телефоном
- Встроенный **HTTP-сервер** прямо в приложении.
- Управление с телефона через браузер (тот же Wi-Fi).
- **Авто-PIN** и **авто-порт** — генерируются один раз и хранятся в `%APPDATA%`.
- **QR-код** для быстрого подключения.

### 🖥 Системный трей
- Иконка меняется, тултип показывает остаток таймера.
- Меню: показать / пауза / отменить / проверить обновления / выход.
- Сворачивание в трей вместо закрытия.

### 🔄 Авто-обновление
- Проверка новых версий через GitHub Releases.
- Скачивание `.exe` с прогресс-баром.
- Самоподмена файла через `.bat` + перезапуск.

### 🎨 Оформление
- Тёмная и светлая темы.
- Скруглённые углы, тонкие границы, плавные анимации кнопок.
- Своя иконка (поддерживается `assets/icon.png` любого размера).
- Кастомный title bar с перетаскиванием.

### 📊 Дополнительно
- Уведомления Windows за N секунд до действия.
- Звуковой сигнал.
- Автозапуск при входе в Windows (реестр).
- Настройки в `%APPDATA%\ShutdownTimer\config.json`.
- Логи в `%APPDATA%\ShutdownTimer\app.log`.
- Защита от второго запуска (Mutex).

## 🚀 Установка

### Вариант 1: Готовый `.exe` (рекомендуется)

1. Откройте раздел [Releases](https://github.com/itired1/pcoff/releases).
2. Скачайте последний `ShutdownTimer.exe`.
3. Запустите — Windows попросит права администратора (нужно для `shutdown`).
4. Готово.

### Вариант 2: Из исходников

```bash
git clone https://github.com/itired1/pcoff.git
cd pcoff
pip install -r requirements.txt
python shutdown_timer.py
```

Требуется **Python 3.10+**.

## 🛠 Сборка `.exe`

### Быстрый способ — `build.bat`

Поместите `build.bat` в папку с `shutdown_timer.py` и запустите двойным кликом.

```bat
@echo off
chcp 65001 >nul
title Сборка Shutdown Timer
color 0A

echo ============================================
echo   Сборка Shutdown Timer v1.3.0
echo ============================================
echo.

where python >nul 2>&1
if errorlevel 1 (
    echo [ОШИБКА] Python не найден в PATH
    pause
    exit /b 1
)

echo [1/4] Проверка PyInstaller...
python -m pip show pyinstaller >nul 2>&1
if errorlevel 1 (
    echo      Установка PyInstaller...
    python -m pip install pyinstaller
)

echo [2/4] Генерация icon.ico из icon.png...
if not exist "assets" mkdir assets
if exist "assets\icon.png" (
    python -c "from PIL import Image; img=Image.open('assets/icon.png').convert('RGBA').resize((256,256), Image.LANCZOS); img.save('assets/icon.ico', sizes=[(16,16),(24,24),(32,32),(48,48),(64,64),(128,128),(256,256)])"
    echo      OK
) else (
    echo      [ВНИМАНИЕ] assets\icon.png не найден
)

echo [3/4] Очистка...
if exist "build" rmdir /s /q "build"
if exist "dist" rmdir /s /q "dist"
if exist "ShutdownTimer.spec" del /q "ShutdownTimer.spec"

echo [4/4] Сборка .exe...
pyinstaller --noconfirm --onefile --windowed ^
  --name="ShutdownTimer" ^
  --uac-admin ^
  --add-data "assets;assets" ^
  --icon="assets\icon.ico" ^
  shutdown_timer.py

if errorlevel 1 (
    echo.
    echo [ОШИБКА] Сборка не удалась
    pause
    exit /b 1
)

echo.
echo ============================================
echo   ГОТОВО!
echo   Файл: dist\ShutdownTimer.exe
echo ============================================
pause
```

### Ручная сборка

**В PowerShell (одной строкой):**

```powershell
pyinstaller --noconfirm --onefile --windowed --name="ShutdownTimer" --uac-admin --add-data "assets;assets" --icon="assets\icon.ico" shutdown_timer.py
```

**В CMD (многострочно):**

```bat
pyinstaller --noconfirm --onefile --windowed ^
  --name="ShutdownTimer" ^
  --uac-admin ^
  --add-data "assets;assets" ^
  --icon="assets\icon.ico" ^
  shutdown_timer.py
```

Готовый файл появится в `dist\ShutdownTimer.exe`.

## 📖 Использование

### Ввод времени

| Что ввести | Что произойдёт |
|-----------|----------------|
| `30` | через 30 минут |
| `30м`, `30m` | через 30 минут |
| `2ч`, `2h` | через 2 часа |
| `1ч30м` | через 1 час 30 минут |
| `90с` | через 90 секунд |
| `1233` | сегодня в 12:33 (или завтра, если уже прошло) |
| `930` | сегодня в 09:30 |
| `12:33` | сегодня в 12:33 |
| `9` | сегодня в 09:00 |
| `0:00` | ближайшая полночь |
| `завтра в 9` | завтра в 09:00 |
| `tomorrow at 9` | завтра в 09:00 |
| `в обед` | сегодня в 13:00 |
| `вечером` | сегодня в 19:00 |
| `утром` | сегодня/завтра в 08:00 |
| `в полночь` | сегодня/завтра в 00:00 |
| `через час` | через 1 час |
| `через полчаса` | через 30 минут |
| `in 30 minutes` | через 30 минут |

### Триггер «Steam»

1. Начните качать игру в Steam.
2. Откройте вкладку **⚡ События** в приложении.
3. Нажмите **↻** рядом с выпадающим списком.
4. Выберите игру из списка.
5. Нажмите **⚡ АКТИВИРОВАТЬ**.

ПК выключится, **как только завершится установка именно этой игры** —
не важно, что стоит в очереди дальше.

### Синхронизация с телефоном

1. Откройте вкладку **⚙ Настройки** → **Синхронизация с телефоном**.
2. Поставьте галочку **Включить**.
3. Если Windows спросит про брандмауэр — разрешите для **частных сетей**.
4. Наведите камеру телефона на QR-код или отсканируйте ссылку вручную.
5. Управляйте таймером прямо из браузера телефона.

PIN и порт генерируются автоматически при первом запуске и хранятся
в `%APPDATA%\ShutdownTimer\config.json`.

### Автозапуск

Настройки → **Поведение** → **Запускать при входе в Windows**.

Приложение пропишет себя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## 🔄 Авто-обновление

Приложение проверяет новые версии через GitHub Releases.

### Для разработчика

1. Увеличьте `__version__` в `shutdown_timer.py`, например до `1.3.1`.
2. Соберите новый `.exe` через `build.bat`.
3. На GitHub:
   - Releases → **Draft a new release**.
   - **Tag**: `v1.3.1` (обязательно с `v` и совпадает с `__version__`).
   - **Title**: `Release 1.3.1`.
   - **Attach binary**: `dist\ShutdownTimer.exe`.
   - **Publish release**.

### Что увидит пользователь

При следующем запуске приложения в настройках появится баннер:

```
Доступна версия 1.3.1 (у вас 1.3.0)
[⬇ ОБНОВИТЬ ДО 1.3.1]
```

Нажатие на кнопку:
1. Скачает новый `.exe` в `%TEMP%`.
2. Создаст `.bat`, который подменит старый файл.
3. Приложение закроется, `.bat` скопирует новый файл, запустит его и удалится.

> ⚠️ Авто-обновление работает **только** для собранного `.exe`.
> При запуске `.py`-скрипта откроется страница релиза в браузере.

## 💡 Часто задаваемые вопросы

**Приложение требует прав администратора, это нормально?**

Да, это нужно для `shutdown /s /f` и записи в `HKEY_CURRENT_USER`.
Без прав приложение откроется, но команды выключения не сработают.

**Где хранятся настройки?**

`%APPDATA%\ShutdownTimer\config.json` — свой у каждого пользователя Windows.

**Где логи?**

`%APPDATA%\ShutdownTimer\app.log` — с ротацией при 512 КБ.

**Не работает Steam-триггер, что делать?**

1. Убедитесь, что Steam установлен.
2. Начните качать игру в Steam.
3. Нажмите **↻** во вкладке **События**.
4. Если список пуст — откройте `app.log` и пришлите строки с `Steam`.

**Телефон не подключается к синхронизации.**

- Телефон и ПК должны быть в **одной Wi-Fi сети**.
- Проверьте, что брандмауэр разрешает `ShutdownTimer.exe` в **частных сетях**.
- Если не помогает — смените порт в настройках (кнопка 🎲).

**Авто-обновление не находит новую версию.**

- Убедитесь, что в релизе GitHub есть файл `.exe` в assets.
- Тег должен быть формата `v1.3.1` (с префиксом `v`).
- Репозиторий должен быть публичным.
